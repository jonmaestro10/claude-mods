# claude-mods

Claude Code mods, installable from this marketplace.

| Mod | What it does |
| --- | --- |
| [usage-remaining](usage-remaining/) | Status line with remaining 5h / 7d usage and the 5h reset countdown |

## Install

At a Claude Code terminal prompt:

```
/plugin install usage-remaining --marketplace jonmaestro10/claude-mods
```

Answer `y` to add the marketplace, then press Enter to install at user scope.
